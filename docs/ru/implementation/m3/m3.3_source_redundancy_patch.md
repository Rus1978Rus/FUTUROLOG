## 1. Сводка

M3.3 добавляет третью компоненту Objective Layer — `source_redundancy`. Она измеряет, поддержан ли риск-сигнал независимыми источниками, а не каскадом перепечаток одного первоисточника. Entropy-RG не кластеризует тексты и не строит source graph: ENRA передаёт готовый `SourceRegistrySnapshot` с `sources`, `claim_clusters` и `independence_graph`, а Entropy-RG только агрегирует эти структуры. Компонента возвращается в `objective_component_scores`, но Objective Layer остаётся неактивным: `objective_layer_active = false`, `alpha_active = false`, `objective_risk = null`, а `final_score` должен оставаться численно равным M1.4 baseline.

## 2. Спецификация компоненты

### 2.1 Назначение

`source_redundancy` отвечает на вопрос:

```text
Поддержан ли сигнал независимыми источниками?
```

Это не «качество источника» и не «количество публикаций». Один хороший источник — ещё не redundancy. Redundancy появляется, когда несколько независимых источников или claim-кластеров подтверждают один и тот же риск-сигнал.

Отличие от `observer_agreement`:

| Компонента | Что агрегирует |
|---|---|
| `observer_agreement` | Мнения detectors/observers о том, нужно ли флагнуть сигнал |
| `source_redundancy` | Источники/публикации/claim-кластеры, поддерживающие сам claim |

Отличие от Universal Layer:

- Universal Layer не знает явно о независимости источников.
- `source_redundancy` работает с `SourceRegistrySnapshot`.
- Эта компонента проверяет доказательную избыточность сигнала.

Семантика:

```text
value = 0 → нет независимых подтверждений
value = 1 → сигнал поддержан множеством независимых original sources
```

### 2.3 Формула

Для каждого independent cluster:

```text
cluster_independence =
    1.0, если в группе есть хотя бы один source с original_or_derivative == "original"
    0.5, если только derivative / unknown
```

```text
cluster_weight =
    max(reliability_score источников в группе)
```

```text
raw_value =
    sum(cluster_independence × cluster_weight)
    /
    sum(cluster_weight)
```

Coverage factor:

```text
source_count_factor =
    min(1.0, unique_source_count / 3)

cluster_count_factor =
    min(1.0, independent_cluster_count / 3)

coverage_factor =
    min(source_count_factor, cluster_count_factor)
```

Итоговое значение:

```text
value =
    clip(raw_value × coverage_factor, 0, 1)
```

Почему нужен `coverage_factor`:

```text
1 original source с reliability=1.0:
    raw_value = 1.0
    source_count_factor = 1/3
    cluster_count_factor = 1/3
    value ≈ 0.33

3 independent original clusters:
    raw_value ≈ 1.0
    coverage_factor = 1.0
    value ≈ 1.0

20 derivative sources в одном cluster:
    raw_value ≈ 0.5
    cluster_count_factor = 1/3
    value ≈ 0.17
```

Confidence:

```text
base_confidence_by_count:
    0 sources → 0.0
    1 source  → 0.3
    2 sources → 0.6
    3+ sources → 0.9
```

```text
reliability_factor =
    mean(clip(reliability_score, 0, 1)) среди всех sources
```

```text
confidence =
    clip(base_confidence × reliability_factor, 0, 1)
```

Если `independence_graph` отсутствует:

```text
confidence *= 0.7
partial = true
reason = "independence_graph_missing"
```

### 2.4 Поведение при граничных случаях

- `source_registry = None` → `return None`.
- `source_registry.sources = []` → `return None`.
- `1 source` → `partial = true`, `base_confidence = 0.3`, `coverage_factor <= 1/3`.
- `2 sources` → `partial = true`, `base_confidence = 0.6`, `coverage_factor <= 2/3`.
- `3+ sources` → `base_confidence = 0.9`, но `partial` может стать true из-за missing graph, truncation, unknown origins или single effective cluster.
- Все sources derivative → `cluster_independence = 0.5`, `raw_value <= 0.5`.
- Все sources unknown → unknown трактуется как derivative-like, reason `source_origin_unknown_treated_as_derivative`.
- Все reliability = 0 → `return None`.
- `claim_clusters` пустой → fallback singleton clusters + reason `claim_clusters_missing_singleton_fallback`.
- `independence_graph` отсутствует → расчёт продолжается, confidence ×= 0.7, `partial=True`.
- 500+ sources → взять последние 500 по `first_seen`, reason `sources_truncated_to_500`.
- 200+ clusters → взять первые 200 по deterministic key order, reason `claim_clusters_truncated_to_200`.

[OPEN_QUESTION] Если ENRA добавит `last_seen` на cluster level, truncation should use latest clusters by last_seen. В M3.3 `claim_clusters` — это `dict[str, list[str]]`, поэтому timestamp у cluster отсутствует.

### 3.2 Новый модуль app/objective/source_redundancy.py

```python
"""
Source redundancy component for Entropy-RG Objective Layer.

This component answers the question:
"Is the signal supported by independent sources?"

It does not perform text clustering, TF-IDF, cosine similarity,
embeddings, scraping, or source registry construction. ENRA prepares
SourceRegistrySnapshot and passes it into Entropy-RG.

M3.3 behavior:
- computes ObjectiveComponentResult if source_registry is present;
- returns None if there are no usable sources or all reliability is zero;
- does not activate Objective Layer;
- does not change final_score;
- does not import app.scoring;
- does not do I/O.
"""

from __future__ import annotations

from datetime import datetime, timezone

from app.objective.types import (
    ObjectiveComponentResult,
    ObjectiveLayerContext,
    SourceMetadata,
)


MAX_SOURCES_PER_REQUEST = 500
MAX_CLUSTERS_PER_REQUEST = 200

VALID_ORIGIN_TYPES = {"original", "derivative", "unknown"}

BASE_CONFIDENCE_BY_COUNT = {
    0: 0.0,
    1: 0.3,
    2: 0.6,
}

FULL_COUNT_CONFIDENCE = 0.9
COVERAGE_DENOMINATOR = 3
```

```python
def clip_01(value: float) -> float:
    return max(0.0, min(1.0, float(value)))


def parse_timestamp(value: str) -> datetime:
    """
    Parse timestamp for sorting/truncation.

    Invalid timestamps are sorted as oldest by returning datetime.min UTC.
    """
    if not value:
        return datetime.min.replace(tzinfo=timezone.utc)

    try:
        normalized = value.replace("Z", "+00:00")
        parsed = datetime.fromisoformat(normalized)
    except ValueError:
        return datetime.min.replace(tzinfo=timezone.utc)

    if parsed.tzinfo is None:
        parsed = parsed.replace(tzinfo=timezone.utc)

    return parsed.astimezone(timezone.utc)


def truncate_sources(
    sources: list[SourceMetadata],
    limit: int = MAX_SOURCES_PER_REQUEST,
) -> tuple[list[SourceMetadata], list[str]]:
    reasons: list[str] = []

    if len(sources) <= limit:
        return sources, reasons

    sorted_sources = sorted(sources, key=lambda item: parse_timestamp(item.first_seen))
    truncated = sorted_sources[-limit:]
    reasons.append(f"sources_truncated_to_{limit}")
    return truncated, reasons


def truncate_clusters(
    claim_clusters: dict[str, list[str]],
    limit: int = MAX_CLUSTERS_PER_REQUEST,
) -> tuple[dict[str, list[str]], list[str]]:
    reasons: list[str] = []

    if len(claim_clusters) <= limit:
        return claim_clusters, reasons

    selected_keys = sorted(claim_clusters.keys())[:limit]
    truncated = {key: claim_clusters[key] for key in selected_keys}
    reasons.append(f"claim_clusters_truncated_to_{limit}")
    return truncated, reasons


def classify_source_origin(source: SourceMetadata) -> str:
    """
    Map original_or_derivative to one of {"original", "derivative", "unknown"}.

    Any invalid value is treated as "unknown".
    Unknown is handled as derivative-like by cluster independence logic.
    """
    value = (source.original_or_derivative or "unknown").lower()
    if value not in VALID_ORIGIN_TYPES:
        return "unknown"
    return value


def base_confidence_for_count(count: int) -> tuple[float, bool]:
    """
    Returns (base_confidence, partial_by_count).
    """
    if count <= 0:
        return 0.0, True
    if count in BASE_CONFIDENCE_BY_COUNT:
        return BASE_CONFIDENCE_BY_COUNT[count], True
    return FULL_COUNT_CONFIDENCE, False


def build_source_to_clusters(
    claim_clusters: dict[str, list[str]],
) -> dict[str, list[str]]:
    source_to_clusters: dict[str, list[str]] = {}
    for cluster_id, source_ids in claim_clusters.items():
        for source_id in source_ids:
            source_to_clusters.setdefault(source_id, []).append(cluster_id)
    return source_to_clusters


def compute_independent_clusters(
    claim_clusters: dict[str, list[str]],
    independence_graph: dict[str, list[str]],
) -> list[list[str]]:
    """
    Compute effective independent groups via union-find on claim_clusters.

    Two claim_clusters merge into one effective cluster if:
    - any source in cluster_A is connected to any source in cluster_B through
      independence_graph; or
    - the clusters share a source_id.

    independence_graph is interpreted as undirected for reading purposes.
    Returns list of flat source_id lists.
    """
    if not claim_clusters:
        return []

    parent: dict[str, str] = {}

    def find(x: str) -> str:
        parent.setdefault(x, x)
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(a: str, b: str) -> None:
        ra, rb = find(a), find(b)
        if ra != rb:
            parent[ra] = rb

    cluster_ids = list(claim_clusters.keys())
    for cluster_id in cluster_ids:
        parent.setdefault(cluster_id, cluster_id)

    source_to_clusters = build_source_to_clusters(claim_clusters)

    # Merge clusters sharing the same source.
    for source_id, cluster_list in source_to_clusters.items():
        if len(cluster_list) > 1:
            first = cluster_list[0]
            for other in cluster_list[1:]:
                union(first, other)

    # Symmetric read of graph: A -> B implies B -> A for grouping.
    undirected_edges: list[tuple[str, str]] = []
    for source_id, correlated_ids in (independence_graph or {}).items():
        for correlated_id in correlated_ids:
            undirected_edges.append((source_id, correlated_id))
            undirected_edges.append((correlated_id, source_id))

    # Merge clusters connected through graph edges.
    for source_id, correlated_id in undirected_edges:
        clusters_a = source_to_clusters.get(source_id, [])
        clusters_b = source_to_clusters.get(correlated_id, [])
        for cluster_a in clusters_a:
            for cluster_b in clusters_b:
                union(cluster_a, cluster_b)

    groups: dict[str, list[str]] = {}
    for cluster_id in cluster_ids:
        root = find(cluster_id)
        groups.setdefault(root, []).append(cluster_id)

    result: list[list[str]] = []
    for grouped_cluster_ids in groups.values():
        source_ids_in_group: list[str] = []
        seen: set[str] = set()
        for cluster_id in grouped_cluster_ids:
            for source_id in claim_clusters[cluster_id]:
                if source_id not in seen:
                    source_ids_in_group.append(source_id)
                    seen.add(source_id)
        result.append(source_ids_in_group)

    return result


def compute_cluster_independence(
    group_meta: list[SourceMetadata],
) -> tuple[float, int]:
    """
    Returns (cluster_independence, unknown_origin_count).

    - 1.0 if at least one original source exists.
    - 0.5 otherwise.
    Unknown is derivative-like.
    """
    unknown_count = 0
    has_original = False

    for source in group_meta:
        origin = classify_source_origin(source)
        if origin == "original":
            has_original = True
        elif origin == "unknown":
            unknown_count += 1

    return (1.0 if has_original else 0.5), unknown_count


def compute_cluster_weight(group_meta: list[SourceMetadata]) -> float:
    """
    Cluster weight is max clipped reliability score among sources in the group.
    """
    if not group_meta:
        return 0.0
    return max(clip_01(source.reliability_score) for source in group_meta)
```

```python
def build_valid_clusters(
    claim_clusters: dict[str, list[str]],
    sources: list[SourceMetadata],
) -> tuple[dict[str, list[str]], list[str]]:
    reasons: list[str] = []
    source_ids = {source.source_id for source in sources}

    valid_clusters = {
        cluster_id: [source_id for source_id in cluster_sources if source_id in source_ids]
        for cluster_id, cluster_sources in claim_clusters.items()
    }
    valid_clusters = {
        cluster_id: cluster_sources
        for cluster_id, cluster_sources in valid_clusters.items()
        if cluster_sources
    }

    if not valid_clusters:
        valid_clusters = {
            f"singleton_{source.source_id}": [source.source_id]
            for source in sources
        }
        reasons.append("claim_clusters_missing_singleton_fallback")

    return valid_clusters, reasons


def compute_source_redundancy(
    context: ObjectiveLayerContext,
) -> ObjectiveComponentResult | None:
    """
    Compute source redundancy for Objective Layer.
    """
    registry = context.source_registry
    if registry is None:
        return None

    if not registry.sources:
        return None

    sources, source_reasons = truncate_sources(list(registry.sources))
    if not sources:
        return None

    claim_clusters, cluster_reasons = truncate_clusters(dict(registry.claim_clusters or {}))

    valid_clusters, valid_cluster_reasons = build_valid_clusters(
        claim_clusters=claim_clusters,
        sources=sources,
    )

    total_reliability = sum(clip_01(source.reliability_score) for source in sources)
    if total_reliability <= 0.0:
        return None

    independence_graph = registry.independence_graph or {}
    graph_missing = not bool(independence_graph)

    independent_groups = compute_independent_clusters(
        claim_clusters=valid_clusters,
        independence_graph=independence_graph,
    )

    if not independent_groups:
        return None

    sources_by_id = {source.source_id: source for source in sources}

    sum_independence_weighted = 0.0
    sum_weights = 0.0
    unknown_origin_count = 0

    for group_source_ids in independent_groups:
        group_meta = [
            sources_by_id[source_id]
            for source_id in group_source_ids
            if source_id in sources_by_id
        ]
        if not group_meta:
            continue

        cluster_independence, group_unknown_count = compute_cluster_independence(group_meta)
        cluster_weight = compute_cluster_weight(group_meta)

        unknown_origin_count += group_unknown_count

        sum_independence_weighted += cluster_independence * cluster_weight
        sum_weights += cluster_weight

    if sum_weights <= 0.0:
        return None

    raw_value = sum_independence_weighted / sum_weights

    unique_source_count = len({source.source_id for source in sources})
    independent_cluster_count = len(independent_groups)

    source_count_factor = min(1.0, unique_source_count / COVERAGE_DENOMINATOR)
    cluster_count_factor = min(1.0, independent_cluster_count / COVERAGE_DENOMINATOR)
    coverage_factor = min(source_count_factor, cluster_count_factor)

    value = clip_01(raw_value * coverage_factor)

    base_confidence, partial = base_confidence_for_count(len(sources))
    reliability_factor = clip_01(total_reliability / len(sources))
    confidence = clip_01(base_confidence * reliability_factor)

    reasons: list[str] = []
    reasons.extend(source_reasons)
    reasons.extend(cluster_reasons)
    reasons.extend(valid_cluster_reasons)

    missing_inputs: list[str] = []

    if len(sources) < 3:
        missing_inputs.append("source_registry.sources.minimum_3")

    if graph_missing:
        confidence = clip_01(confidence * 0.7)
        partial = True
        reasons.append("independence_graph_missing")
        missing_inputs.append("source_registry.independence_graph")

    if unknown_origin_count > 0:
        partial = True
        reasons.append("source_origin_unknown_treated_as_derivative")
        reasons.append(f"unknown_origin_count_{unknown_origin_count}")

    if independent_cluster_count == 1 and len(sources) > 1:
        partial = True
        reasons.append("all_sources_in_single_independent_cluster")

    if independent_cluster_count >= 3:
        reasons.append("multi_cluster_independent_support")

    reasons.append(f"source_count_{len(sources)}")
    reasons.append(f"unique_source_count_{unique_source_count}")
    reasons.append(f"independent_cluster_count_{independent_cluster_count}")

    return ObjectiveComponentResult(
        value=value,
        confidence=confidence,
        missing_inputs=missing_inputs,
        reasons=reasons,
        partial=partial,
    )
```

### Важные правила реализации

- `coverage_factor` применяется ровно один раз: `value = raw_value × coverage_factor`.
- Unknown origin — derivative-like, не original.
- Если `independence_graph` missing, расчёт не блокируется, но confidence снижается на 30%.
- `claim_clusters` fallback к singleton clusters нужен только когда кластеры отсутствуют или после filtering пустые.
- Никакого TF-IDF/cosine/embeddings.

Добавить:

```markdown
## source_redundancy

Status: implemented in M3.3, informational only.

source_redundancy measures whether a signal is supported by independent
sources rather than a repost/media cascade.

Responsibility boundary:
- ENRA builds claim_clusters and independence_graph.
- Entropy-RG aggregates SourceRegistrySnapshot.
- Entropy-RG does not perform text similarity, TF-IDF, cosine, embeddings,
  scraping, or source crawling.

Formula summary:
cluster_independence = 1.0 if cluster contains an original source, else 0.5.
cluster_weight = max reliability_score in cluster.
raw_value = weighted mean of cluster_independence.
coverage_factor = min(unique_source_count / 3, independent_cluster_count / 3, 1).
value = raw_value × coverage_factor.

If independence_graph is missing:
- computation continues;
- confidence is multiplied by 0.7;
- partial=True;
- reason="independence_graph_missing".

source_redundancy does not change final_score in M3.3.
Objective Layer remains inactive until M3.6.
```

## 6. Риски

## Risk 1: integration с integrate_scores меняет final_score

Detection: `test_final_score_unchanged_after_m3_3`; сравнение с M1.4 baseline.  
Mitigation: компонент добавляется только в `objective_component_scores`; не менять `final_score`, `universal_risk`, weights.

## Risk 2: union-find работает некорректно на больших графах

Detection: clustering tests + media wave scenario.  
Mitigation: union-find только по cluster_ids; merge clusters sharing source; symmetric read of graph edges.

## Risk 3: claim_clusters содержит unknown source_ids

Detection: test with unknown source_id in cluster. [REQUIRES_VERIFICATION]  
Mitigation: filter clusters to known source_ids; drop empty clusters; fallback to singleton clusters if no valid clusters remain.

## Risk 4: independence_graph асимметричный

Detection: `test_asymmetric_graph_normalized`.  
Mitigation: read graph symmetrically.

## Risk 5: ENRA передаёт пустой independence_graph как dict()

Detection: `test_independence_graph_missing_penalty`.  
Mitigation: confidence ×= 0.7; `partial=True`; reason `independence_graph_missing`.

## Risk 6: source с reliability=0 включается в подсчёт sources

Detection: test with zero reliability mixed sources. [OPEN_QUESTION]  
Mitigation: рекомендовано исключать zero-reliability sources из coverage count в будущей правке, чтобы fake zero-reliability sources не раздували redundancy. В M3.3 all-zero returns None.

## Risk 7: дубликаты source_id в одном кластере

Detection: clustering tests with duplicate source ids. [REQUIRES_VERIFICATION]  
Mitigation: `compute_independent_clusters` flattens with `seen`; `unique_source_count` uses set.

## Risk 8: timestamp first_seen в разных форматах при truncation

Detection: truncation tests with `Z`, `+00:00`, naive timestamps.  
Mitigation: `parse_timestamp` normalizes to UTC; invalid timestamps sorted as oldest.

## Risk 9: COVERAGE_DENOMINATOR = 3 слишком жёсткое или мягкое
