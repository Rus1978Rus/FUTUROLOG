# M3.4 Noise Separation Patch

# Реализация компоненты noise_separation для Objective Layer

Статус: patch-документ для M3.4  
Проект: «Футуролог»  
Пакет: Entropy-RG v3.x  
Основание: `objective_layer_design_v1.md`, `m3_1_temporal_persistence_patch.md`, `m3_2_observer_agreement_patch.md`, `m3_3_source_redundancy_patch.md`, `futurolog_architecture_v1.1.md`  
Цель: добавить четвёртую компоненту Objective Layer без активации Objective Layer и без изменения `final_score`

Важно: исходное задание в текущем сообщении обрывается на фразе `distribution содержит p95...`. Поэтому часть граничных случаев ниже восстановлена по уже заданным решениям M3.4 и помечена `[REQUIRES_VERIFICATION]`, если требует подтверждения автора.

## 1. Сводка

M3.4 добавляет компоненту `noise_separation`, которая измеряет, насколько `universal_risk` отделён от шумового фона. Компонента использует `NoiseBaselineSnapshot`, переданный ENRA через `ObjectiveLayerContext`, и сравнивает текущий `universal_risk` с квантилями шумового распределения `p50`, `p75`, `p90`, `p95`. Результат возвращается в `objective_component_scores["noise_separation"]`, но Objective Layer не активируется: `objective_layer_active = false`, `alpha_active = false`, `objective_risk = null`, а `final_score` остаётся численно равным M1.4 baseline.

M3.4 также добавляет `noise_baseline` в `ObjectiveLayerContext`. Это даёт ожидаемый побочный эффект: `temporal_persistence` из M3.1 может начать использовать `noise_baseline.percentile_75` / `p75` как threshold вместо default `0.5`, если baseline передан. Это меняет только objective-only значения, но не Universal Layer и не `final_score`.

## 2. Спецификация компоненты

### 2.1 Назначение

`noise_separation` отвечает на вопрос:

```text
Можно ли отличить текущий universal_risk от обычного шумового фона?
```

Семантика:

```text
value = 0 → universal_risk на уровне или ниже медианы шума
value = 1 → universal_risk выше p95 шумового распределения
```

Отличие от `source_redundancy`:

- `source_redundancy` проверяет независимые источники;
- `noise_separation` проверяет статистическое отделение от фонового шума.

Отличие от `temporal_persistence`:

- `temporal_persistence` проверяет устойчивость во времени;
- `noise_separation` проверяет, насколько текущий риск выше фонового распределения.

`noise_separation` не строит baseline самостоятельно. ENRA отвечает за `NoiseBaselineCollector` и передаёт snapshot в Entropy-RG.

### 2.3 NoiseBaselineSnapshot

Добавить в `app/objective/types.py`:

```python
@dataclass
class NoiseBaselineSnapshot:
    noise_score_distribution: dict  # quantiles: p50, p75, p90, p95
    sample_size: int
    window: str
```

Минимально требуемые ключи:

```text
p50, p75, p95
```

Опциональный ключ:

```text
p90
```

Все значения должны быть в `[0, 1]`.

### 2.4 Формула value

Пусть:

```text
p50 = noise.noise_score_distribution["p50"]
p75 = noise.noise_score_distribution["p75"]
p95 = noise.noise_score_distribution["p95"]
u = universal_risk
```

Формула:

```text
if u <= p50:
    value = 0.0

elif u <= p75:
    value = clip((u - p50) / (p75 - p50), 0, 1) × 0.3

elif u <= p95:
    value = 0.3 + 0.7 × (u - p75) / (p95 - p75)

else:
    value = 1.0
```

Защита от деления на ноль:

```text
если p75 == p50:
    value на сегменте p50..p75 = 0.3

если p95 == p75:
    value на сегменте p75..p95 = 1.0
```

Интерпретация:

- зона `p50..p75` даёт только нижние 30% confidence of separation;
- зона `p75..p95` даёт основной рост separation;
- выше `p95` — максимально отделённый сигнал.

### 2.5 Confidence

```text
sample_size_factor = clip(sample_size / 1000, 0, 1)
```

```text
distribution_quality_factor =
    1.0 если p50, p75, p90, p95 присутствуют и p50 <= p75 <= p90 <= p95
    0.7 если присутствуют p50, p75, p95, но p90 отсутствует
```

Если порядок квантилей нарушен:

```text
return None
reason = "noise_distribution_invalid_quantile_order"
```

Формула:

```text
confidence =
    clip(sample_size_factor × distribution_quality_factor, 0, 1)
```

Partial:

```text
partial = true если:
- p90 отсутствует;
- sample_size < 1000;
- baseline window слишком короткое или unknown;
- noise_baseline используется как fallback/approximation.
```

### 2.6 Поведение при граничных случаях

- `context.noise_baseline = None` → `return None`.
- `noise_baseline.sample_size == 0` → `return None`.
- `noise_baseline.sample_size < 50` → `return None` и reason `noise_baseline_too_small`.
- Отсутствуют `p50`, `p75`, `p95` → `return None`, reason `noise_distribution_missing_required_quantiles`.
- Отсутствует только `p90` → расчёт разрешён, `partial=True`, `distribution_quality_factor=0.7`, reason `noise_distribution_missing_quantile_p90`.
- Значения квантилей вне `[0, 1]` → clipped или invalid?  
  Решение M3.4: clipped для safety, но добавить reason `noise_quantile_clipped_to_unit_range`. [REQUIRES_VERIFICATION]
- Нарушен порядок `p50 <= p75 <= p90 <= p95` или `p50 <= p75 <= p95` без p90 → `return None`, reason `noise_distribution_invalid_quantile_order`.
- `p75 == p50` → не падать, использовать boundary value `0.3`, reason `noise_distribution_degenerate_p50_p75`.
- `p95 == p75` → не падать, использовать boundary value `1.0`, reason `noise_distribution_degenerate_p75_p95`.
- `universal_risk < 0` или `> 1` → clip в `[0, 1]`, reason `universal_risk_clipped_to_unit_range`.
- `window` неизвестен → расчёт разрешён, `partial=True`, reason `noise_baseline_unknown_window`.

### 3.2 Новый модуль app/objective/noise_separation.py

```python
"""
Noise separation component for Entropy-RG Objective Layer.

This component answers the question:
"Is the current universal risk separated from normal noise?"

It compares universal_risk with a noise baseline distribution supplied
by ENRA through ObjectiveLayerContext.noise_baseline.

M3.4 behavior:
- computes ObjectiveComponentResult when noise_baseline is present;
- returns None when baseline is missing, too small, or invalid;
- does not collect or update noise baseline;
- does not activate Objective Layer;
- does not change final_score;
- does not import app.scoring;
- does not do I/O.
"""

from __future__ import annotations

from app.objective.types import (
    NoiseBaselineSnapshot,
    ObjectiveComponentResult,
    ObjectiveLayerContext,
)


REQUIRED_QUANTILES = ("p50", "p75", "p95")
OPTIONAL_QUANTILES = ("p90",)

MIN_SAMPLE_SIZE = 50
FULL_CONFIDENCE_SAMPLE_SIZE = 1000

KNOWN_NOISE_WINDOWS = {"1h", "1d", "1w", "7d", "30d", "90d"}


def clip_01(value: float) -> float:
    return max(0.0, min(1.0, float(value)))


def get_quantile(
    distribution: dict,
    key: str,
    reasons: list[str],
) -> float | None:
    if key not in distribution:
        return None

    raw = distribution[key]
    try:
        value = float(raw)
    except (TypeError, ValueError):
        reasons.append(f"noise_distribution_invalid_quantile_{key}")
        return None

    clipped = clip_01(value)
    if clipped != value:
        reasons.append("noise_quantile_clipped_to_unit_range")

    return clipped


def validate_and_extract_quantiles(
    baseline: NoiseBaselineSnapshot,
) -> tuple[dict[str, float] | None, list[str], bool]:
    """
    Returns:
        (quantiles_or_none, reasons, partial)
    """
    reasons: list[str] = []
    partial = False

    distribution = baseline.noise_score_distribution or {}

    missing_required = [
        key for key in REQUIRED_QUANTILES
        if key not in distribution
    ]
    if missing_required:
        reasons.append("noise_distribution_missing_required_quantiles")
        for key in missing_required:
            reasons.append(f"noise_distribution_missing_quantile_{key}")
        return None, reasons, True

    quantiles: dict[str, float] = {}
    for key in REQUIRED_QUANTILES:
        value = get_quantile(distribution, key, reasons)
        if value is None:
            return None, reasons, True
        quantiles[key] = value

    if "p90" in distribution:
        p90 = get_quantile(distribution, "p90", reasons)
        if p90 is None:
            return None, reasons, True
        quantiles["p90"] = p90
    else:
        partial = True
        reasons.append("noise_distribution_missing_quantile_p90")

    p50 = quantiles["p50"]
    p75 = quantiles["p75"]
    p95 = quantiles["p95"]

    if "p90" in quantiles:
        if not (p50 <= p75 <= quantiles["p90"] <= p95):
            reasons.append("noise_distribution_invalid_quantile_order")
            return None, reasons, True
    else:
        if not (p50 <= p75 <= p95):
            reasons.append("noise_distribution_invalid_quantile_order")
            return None, reasons, True

    if p75 == p50:
        reasons.append("noise_distribution_degenerate_p50_p75")
    if p95 == p75:
        reasons.append("noise_distribution_degenerate_p75_p95")

    return quantiles, reasons, partial


def compute_noise_separation_value(
    universal_risk: float,
    p50: float,
    p75: float,
    p95: float,
) -> float:
    u = clip_01(universal_risk)

    if u <= p50:
        return 0.0

    if u <= p75:
        if p75 == p50:
            return 0.3
        return clip_01((u - p50) / (p75 - p50)) * 0.3

    if u <= p95:
        if p95 == p75:
            return 1.0
        return clip_01(0.3 + 0.7 * ((u - p75) / (p95 - p75)))

    return 1.0


def compute_noise_separation(
    context: ObjectiveLayerContext,
    universal_risk: float,
) -> ObjectiveComponentResult | None:
    """
    Compute separation between universal_risk and noise baseline.
    """
    baseline = context.noise_baseline
    if baseline is None:
        return None

    reasons: list[str] = []
    missing_inputs: list[str] = []
    partial = False

    if baseline.sample_size <= 0:
        return None

    if baseline.sample_size < MIN_SAMPLE_SIZE:
        # Component is treated as missing at aggregator level.
        return None

    if baseline.window not in KNOWN_NOISE_WINDOWS:
        partial = True
        reasons.append("noise_baseline_unknown_window")

    quantiles, quantile_reasons, quantile_partial = validate_and_extract_quantiles(baseline)
    reasons.extend(quantile_reasons)
    partial = partial or quantile_partial

    if quantiles is None:
        return None

    original_universal_risk = float(universal_risk)
    clipped_universal_risk = clip_01(original_universal_risk)
    if clipped_universal_risk != original_universal_risk:
        reasons.append("universal_risk_clipped_to_unit_range")

    value = compute_noise_separation_value(
        universal_risk=clipped_universal_risk,
        p50=quantiles["p50"],
        p75=quantiles["p75"],
        p95=quantiles["p95"],
    )

    sample_size_factor = clip_01(
        baseline.sample_size / FULL_CONFIDENCE_SAMPLE_SIZE
    )

    if "p90" in quantiles:
        distribution_quality_factor = 1.0
    else:
        distribution_quality_factor = 0.7
        partial = True

    confidence = clip_01(sample_size_factor * distribution_quality_factor)

    if baseline.sample_size < FULL_CONFIDENCE_SAMPLE_SIZE:
        partial = True
        reasons.append("noise_baseline_sample_size_below_full_confidence")

    reasons.append(f"noise_baseline_sample_size_{baseline.sample_size}")
    reasons.append(f"noise_baseline_window_{baseline.window}")

    return ObjectiveComponentResult(
        value=value,
        confidence=confidence,
        missing_inputs=missing_inputs,
        reasons=reasons,
        partial=partial,
    )
```

```markdown
## noise_separation

Status: implemented in M3.4, informational only.

noise_separation measures whether current universal_risk is separated
from the noise baseline distribution.

Responsibility boundary:
- ENRA collects and updates NoiseBaselineSnapshot.
- Entropy-RG only reads the snapshot and computes separation.
- Entropy-RG does not build the baseline.

Required quantiles:
- p50
- p75
- p95

Optional:
- p90

Formula:
- u <= p50 → value = 0
- p50 < u <= p75 → value grows from 0 to 0.3
- p75 < u <= p95 → value grows from 0.3 to 1.0
- u > p95 → value = 1.0

Side effect:
After M3.4, temporal_persistence may use noise_baseline.p75 as threshold
instead of default 0.5. This can change objective_component_scores but
must not change final_score while Objective Layer is inactive.

noise_separation does not change final_score in M3.4.
Objective Layer remains inactive until M3.6.
```

## 6. Риски

## Risk 1: integration с integrate_scores меняет final_score

## Risk 2: temporal_persistence objective score меняется и это принимают за regression

Detection: test explicitly says objective scores may change.  
Mitigation: regression compares only `final_score` and `universal_risk`.

## Risk 3: quantile order invalid

Detection: `test_invalid_quantile_order_returns_none`.  
Mitigation: validate `p50 <= p75 <= p90 <= p95` or `p50 <= p75 <= p95`.

## Risk 4: sample_size слишком мал

Detection: `test_too_small_sample_size_returns_none`.  
Mitigation: `MIN_SAMPLE_SIZE = 50`.

Mitigation: boundary values 0.3 and 1.0.

Mitigation: strict `NoiseBaselineSnapshotSchema`.
