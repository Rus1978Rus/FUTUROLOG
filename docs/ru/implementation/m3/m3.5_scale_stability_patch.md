## 1. Сводка

M3.5 добавляет последнюю компоненту Objective Layer — `scale_stability`. Она измеряет, сохраняется ли риск-сигнал при переходе между уровнями агрегации: `event → actor → topic → macro_topic → community → global`. Это центральная ERG-CAD идея: риск — это persistence of information across scales. Компонента использует готовый `ScaleAggregatesSnapshot`, который собирает ENRA, и возвращает результат в `objective_component_scores["scale_stability"]`. Objective Layer в M3.5 всё ещё не активируется: `objective_layer_active = false`, `alpha_active = false`, `objective_risk = null`, а `final_score` должен оставаться численно равным M1.4 baseline. В документации M3.5 явно фиксируется, что `scale_stability` обязательна для активации Objective Layer в M3.6.

## 2. Спецификация компоненты

### 2.1 Назначение

`scale_stability` отвечает на вопрос:

```text
Сохраняется ли риск-сигнал при coarse-graining между уровнями?
```

Семантика:

```text
value = 0 → сигнал теряется при переходе между масштабами
value = 1 → сигнал устойчив на всех доступных уровнях
```

Отличие от `temporal_persistence`:

| Компонента | Что проверяет |
|---|---|
| `temporal_persistence` | устойчивость во времени |
| `scale_stability` | устойчивость между уровнями агрегации |

Отличие от `rg_persistence_score`:

| Компонента | Слой | Источник данных |
|---|---|---|
| `rg_persistence_score` | Universal Layer | RG-style coarse-graining внутри scoring core |
| `scale_stability` | Objective Layer | готовые scale aggregates от ENRA |

`scale_stability` не строит уровни сама. ENRA отвечает за агрегацию и передаёт `ScaleAggregatesSnapshot`.

Архитектурное обязательство:

```text
scale_stability обязательна для активации Objective Layer в M3.6.
```

Это не реализуется в M3.5, но должно быть зафиксировано в документации и release notes.

### 2.3 Формула

Канонический порядок уровней:

```python
LEVEL_ORDER = [
    "event",
    "actor",
    "topic",
    "macro_topic",
    "community",
    "global",
]
```

Для каждой пары соседних уровней после сортировки:

```text
preservation_i = 1 - |risk_i - risk_{i+1}|
```

Вес уровня:

```text
level_weight_i = clip(log10(sample_count_i + 1) / 3, 0, 1)
```

Вес пары:

```text
pair_weight_i = min(level_weight_i, level_weight_{i+1})
```

Итоговое значение:

```text
value =
    sum(preservation_i × pair_weight_i)
    /
    sum(pair_weight_i)
```

Если:

```text
sum(pair_weight_i) == 0
```

то компонент возвращает `None`.

Confidence:

```text
base_confidence_by_count:
    2 levels → 0.4
    3 levels → 0.6
    4+ levels → 0.9
```

```text
mean_pair_weight =
    mean(pair_weight_i)
```

```text
confidence =
    clip(base_confidence × mean_pair_weight, 0, 1)
```

Partial:

```text
2 levels → partial=True
3 levels → partial=True
4+ levels → partial=False
```

Дополнительные причины могут снова сделать `partial=True`:

- all unknown levels;
- truncation;
- duplicates;
- invalid sample_count;
- clipped aggregated_risk.

### 2.4 Future calibration note

M3.5 использует симметричную формулу:

```text
preservation = 1 - |risk_i - risk_{i+1}|
```

Это означает, что формула одинаково штрафует:

```text
event=0.8 → global=0.4  # растворение сигнала
event=0.4 → global=0.8  # рост сигнала на higher scale
```

Для футурологии это может быть слишком грубо. Рост риска на более высоких уровнях иногда является признаком emerging trend, а не дефектом стабильности.

Future calibration option for M5:

```text
down_drop = max(0, risk_i - risk_{i+1})
up_growth = max(0, risk_{i+1} - risk_i)

preservation =
    1 - down_drop - 0.5 × up_growth
```

Интерпретация:

- снижение риска на higher scale штрафуется сильнее;
- рост риска на higher scale штрафуется слабее;
- коэффициент `0.5` является calibration parameter.

В M3.5 этот вариант НЕ реализуется. Он фиксируется только как future calibration note.

Причина выбора симметричной формулы для MVP:

- проще тестировать;
- меньше параметров;
- не требует доменной калибровки;
- не подменяет M5 calibration.

### 2.5 Поведение при граничных случаях

- `context.scale_aggregates = None` → `return None`.
- `scale_aggregates.levels = []` → `return None`.
- `len(levels) < 2` после filtering/dedup → `return None`.
- `aggregated_risk < 0` или `> 1` → clip + reason `aggregated_risk_clipped`.
- `sample_count < 0` → `level_weight = 0`, reason `invalid_sample_count`.
- `sum(pair_weights) == 0` → `return None`, reason `all_pair_weights_zero`.
- Unknown levels принимаются, сортируются после known levels, reason `unknown_scale_level_<name>`.
- Все levels unknown → расчёт продолжается в порядке появления, reason `all_unknown_scale_levels`, `partial=True`.
- Дубликаты `level_name` → первое появление сохраняется, следующие отбрасываются, reason `duplicate_scale_level_<level_name>`.
- `len(levels) > 10` → взять первые 10 после сортировки, reason `scale_levels_truncated_to_10`.

### 3.2 Новый модуль app/objective/scale_stability.py

```python
"""
Scale stability component for Entropy-RG Objective Layer.

Central ERG-CAD idea:
"Risk is persistence of information across scales."

The component checks whether the risk signal is preserved when moving
between aggregation levels: event → actor → topic → macro_topic
→ community → global.

Entropy-RG does not aggregate events into levels itself.
ENRA computes aggregated_risk per level and passes ScaleAggregatesSnapshot.

M3.5 behavior:
- computes ObjectiveComponentResult if scale_aggregates are valid;
- returns None if missing, only one level, or all pair weights are zero;
- does not activate Objective Layer;
- does not change final_score;
- does not import app.scoring;
- does not do I/O.

NOTE:
M3.5 uses symmetric preservation: 1 - |Δ risk|.
Asymmetric calibration is left as a future option for M5.
"""

from __future__ import annotations

import math

from app.objective.types import (
    ObjectiveComponentResult,
    ObjectiveLayerContext,
    ScaleLevel,
)


LEVEL_ORDER = [
    "event",
    "actor",
    "topic",
    "macro_topic",
    "community",
    "global",
]

MAX_LEVELS = 10

BASE_CONFIDENCE_BY_COUNT = {
    2: 0.4,
    3: 0.6,
}

FULL_COUNT_CONFIDENCE = 0.9
LOG10_SAMPLE_DENOMINATOR = 3.0


def clip_01(value: float) -> float:
    return max(0.0, min(1.0, float(value)))


def compute_level_weight(sample_count: int) -> tuple[float, list[str]]:
    """
    Compute level reliability weight from sample_count.

    weight = clip(log10(sample_count + 1) / 3, 0, 1)

    sample_count < 0 is invalid and returns 0 weight.
    """
    reasons: list[str] = []

    if sample_count < 0:
        reasons.append("invalid_sample_count")
        return 0.0, reasons

    weight = math.log10(sample_count + 1) / LOG10_SAMPLE_DENOMINATOR
    return clip_01(weight), reasons


def deduplicate_levels(levels: list[ScaleLevel]) -> tuple[list[ScaleLevel], list[str]]:
    """Keep the first occurrence of each level_name."""
    seen: set[str] = set()
    result: list[ScaleLevel] = []
    reasons: list[str] = []

    for level in levels:
        if level.level_name in seen:
            reasons.append(f"duplicate_scale_level_{level.level_name}")
            continue

        seen.add(level.level_name)
        result.append(level)

    return result, reasons


def sort_levels_by_canonical_order(levels: list[ScaleLevel]) -> tuple[list[ScaleLevel], list[str]]:
    """
    Sort levels by LEVEL_ORDER.

    Unknown levels are appended after known levels in their original order.
    """
    reasons: list[str] = []
    indexed_levels = list(enumerate(levels))

    def sort_key(item: tuple[int, ScaleLevel]) -> tuple[int, int]:
        original_index, level = item
        if level.level_name in LEVEL_ORDER:
            return (0, LEVEL_ORDER.index(level.level_name))

        reasons.append(f"unknown_scale_level_{level.level_name}")
        return (1, original_index)

    sorted_items = sorted(indexed_levels, key=sort_key)
    sorted_levels = [level for _, level in sorted_items]

    reasons = list(dict.fromkeys(reasons))

    return sorted_levels, reasons


def truncate_levels(levels: list[ScaleLevel]) -> tuple[list[ScaleLevel], list[str]]:
    reasons: list[str] = []

    if len(levels) > MAX_LEVELS:
        levels = levels[:MAX_LEVELS]
        reasons.append(f"scale_levels_truncated_to_{MAX_LEVELS}")

    return levels, reasons


def base_confidence_for_count(level_count: int) -> tuple[float, bool]:
    """Returns (base_confidence, partial_by_count)."""
    if level_count < 2:
        return 0.0, True

    if level_count in BASE_CONFIDENCE_BY_COUNT:
        return BASE_CONFIDENCE_BY_COUNT[level_count], True

    return FULL_COUNT_CONFIDENCE, False


def compute_preservation(risk_a: float, risk_b: float) -> float:
    """Symmetric MVP preservation formula."""
    return clip_01(1.0 - abs(risk_a - risk_b))


def compute_scale_stability(
    context: ObjectiveLayerContext,
) -> ObjectiveComponentResult | None:
    """Compute scale stability across ScaleAggregatesSnapshot."""
    snapshot = context.scale_aggregates
    if snapshot is None:
        return None

    if not snapshot.levels:
        return None

    raw_levels = list(snapshot.levels)

    deduped_levels, dedup_reasons = deduplicate_levels(raw_levels)
    sorted_levels, sort_reasons = sort_levels_by_canonical_order(deduped_levels)
    levels, truncate_reasons = truncate_levels(sorted_levels)

    if len(levels) < 2:
        return None

    reasons: list[str] = []
    reasons.extend(dedup_reasons)
    reasons.extend(sort_reasons)
    reasons.extend(truncate_reasons)

    risks: list[float] = []
    level_weights: list[float] = []

    clipped_risk_count = 0
    invalid_sample_count_count = 0

    for level in levels:
        raw_risk = float(level.aggregated_risk)
        clipped_risk = clip_01(raw_risk)

        if clipped_risk != raw_risk:
            clipped_risk_count += 1

        risks.append(clipped_risk)

        weight, weight_reasons = compute_level_weight(int(level.sample_count))
        if "invalid_sample_count" in weight_reasons:
            invalid_sample_count_count += 1

        level_weights.append(weight)

    if clipped_risk_count > 0:
        reasons.append("aggregated_risk_clipped")

    if invalid_sample_count_count > 0:
        reasons.append(f"invalid_sample_count_in_{invalid_sample_count_count}_levels")

    pair_preservations: list[float] = []
    pair_weights: list[float] = []

    for idx in range(len(levels) - 1):
        preservation = compute_preservation(risks[idx], risks[idx + 1])
        pair_weight = min(level_weights[idx], level_weights[idx + 1])

        pair_preservations.append(preservation)
        pair_weights.append(pair_weight)

    sum_pair_weights = sum(pair_weights)
    if sum_pair_weights <= 0.0:
        return None

    weighted_sum = sum(
        preservation * weight
        for preservation, weight in zip(pair_preservations, pair_weights)
    )

    value = clip_01(weighted_sum / sum_pair_weights)

    base_confidence, partial = base_confidence_for_count(len(levels))
    mean_pair_weight = sum_pair_weights / len(pair_weights)
    confidence = clip_01(base_confidence * mean_pair_weight)

    known_level_count = sum(1 for level in levels if level.level_name in LEVEL_ORDER)
    if known_level_count == 0:
        reasons.append("all_unknown_scale_levels")
        partial = True

    if clipped_risk_count > 0 or invalid_sample_count_count > 0 or truncate_reasons or dedup_reasons:
        partial = True

    if value > 0.85:
        reasons.append("scale_stability_high")
    elif value < 0.3:
        reasons.append("scale_stability_signal_dissolves")
    else:
        reasons.append("scale_stability_partial")

    if risks[-1] > risks[0] + 0.2:
        reasons.append("scale_emergence_pattern_observed")

    if risks[0] > risks[-1] + 0.2:
        reasons.append("scale_dissolution_pattern_observed")

    reasons.append(f"scale_level_count_{len(levels)}")

    missing_inputs: list[str] = []
    if len(levels) < 4:
        missing_inputs.append("scale_aggregates.levels.minimum_4")

    return ObjectiveComponentResult(
        value=value,
        confidence=confidence,
        missing_inputs=missing_inputs,
        reasons=reasons,
        partial=partial,
    )
```

## scale_stability

Status: implemented in M3.5, informational only.

scale_stability measures whether the risk signal persists across
aggregation levels.

Known levels:

event → actor → topic → macro_topic → community → global

Formula:

preservation_i = 1 - |risk_i - risk_{i+1}|
level_weight_i = clip(log10(sample_count_i + 1) / 3, 0, 1)
pair_weight_i = min(level_weight_i, level_weight_{i+1})

value = weighted mean of preservation_i using pair_weight_i.

Boundary:
- ENRA computes ScaleAggregatesSnapshot.
- Entropy-RG only aggregates the provided levels.
- Entropy-RG does not build scale aggregates.

Activation requirement:
scale_stability is required for Objective Layer activation in M3.6.

Future calibration note:
M3.5 uses symmetric preservation. In M5, an asymmetric preservation
formula may be evaluated to avoid over-penalizing upward scale emergence.
