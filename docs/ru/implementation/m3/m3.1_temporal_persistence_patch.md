# Реализация компоненты temporal_persistence для Objective Layer

Статус: patch-документ для M3.1  
Проект: «Футуролог»  
Пакет: Entropy-RG v3.x  
Основание: `objective_layer_design_v1.md`, `futurolog_architecture_v1.1.md`, `m1_5_documentation_release.md`  
Цель: добавить первую компоненту Objective Layer без активации Objective Layer и без изменения `final_score`

Важно: этот patch-документ подготовлен по архитектурным решениям M3.0/M3.1. Фактический архив `entropy_rg_anomaly_detector_EN_v2_2_FINAL.zip` в текущем контексте не открыт, поэтому места, где требуется сверка с реальным кодом, помечены `[REQUIRES_VERIFICATION]`.

## 1. Сводка

M3.1 добавляет первую компоненту Objective Layer — `temporal_persistence`, которая отвечает на вопрос, сохранялся ли риск-сигнал во времени. Компонента создаётся в новом пакете `app/objective/`, получает `score_history` через `ObjectiveLayerContext`, рассчитывает value/confidence/partial/reasons и возвращается в `objective_component_scores`. Objective Layer при этом остаётся неактивным: `objective_layer_active = false`, `alpha_active = false`, `objective_risk = null`, а `final_score` численно остаётся равным M1.4 baseline. M3.1 не реализует другие objective-компоненты, не меняет веса, не меняет `DEFAULT_GAMMA`, не применяет alpha-формулу и не делает I/O.

## 2. Спецификация компоненты

## 2.1 Назначение

`temporal_persistence` измеряет, сохранялся ли риск-сигнал во времени в разных rolling windows. Она отвечает не на вопрос «есть ли последовательная аномалия формы», а на вопрос «держался ли уровень риска достаточно долго».

Отличие от `sequential_anomaly_score`:

| Компонента | Смысл |
|---|---|
| `sequential_anomaly_score` | Форма/паттерн последовательности, порядок и накопление evidence |
| `temporal_persistence` | Длительность и повторяемость повышенного risk-сигнала во временных окнах |

Семантика:

```text
value = 0 → сигнал не держался во времени
value = 1 → сигнал устойчиво держался во времени
```

Компонента работает только с переданным `score_history`. Она не читает state_store и не собирает историю сама. ScoreHistoryCollector — зона ENRA.

## 2.3 Формула

Фиксированные размеры окон:

```python
WINDOW_SIZES = {"1h", "1d", "1w"}
```

Half-life:

```text
1h → 24 hours
1d → 7 days
1w → 30 days
```

Decay weight:

```text
weight = 0.5 ** (age / half_life)
```

где:

```text
age = current_timestamp - point.timestamp
```

Возраст считается в секундах. Если timestamp точки в будущем, age должен быть clipped до 0 или точка должна быть помечена reason. Рекомендуемое поведение M3.1: `age_seconds = max(0, current - point_time)` и reason `future_timestamp_clipped_to_zero_age`.

Формула на одном window-масштабе:

```text
weighted_sum_above =
    sum(decay(age) × max(0, score - threshold)
        for point in history_of_this_window)

weighted_sum_total =
    sum(decay(age) × (1 - threshold)
        for point in history_of_this_window)

value_per_window =
    clip(weighted_sum_above / weighted_sum_total, 0, 1)
```

Если:

```text
weighted_sum_total = 0
```

то:

```text
value_per_window = 0
confidence_per_window = 0
```

Confidence по длине истории конкретного window:

| Количество точек | Участие | partial для window | confidence |
|---:|---|---|---:|
| 0 | не участвует | true | 0.0 |
| 1 | участвует | true | 0.3 |
| 2 | участвует | true | 0.6 |
| 3+ | участвует | false | 0.9 |

Multi-scale агрегация:

```text
value = mean(value_per_window по доступным window: 1h, 1d, 1w)
```

Confidence aggregation:

```text
confidence =
    weighted average confidence_per_window,
    где вес = количество валидных точек на данном масштабе
```

Partial aggregation:

```text
partial = true если:
- хотя бы один доступный window partial=True;
- или часть масштабов отсутствует;
- или были unknown window sizes;
- или были invalid timestamps;
- или threshold взят из fallback default.
```

## 2.4 Поведение при граничных случаях

### score_history пустой

```text
return None
```

Reasons на уровне caller могут добавить:

```text
"temporal_persistence_missing_score_history"
```

### score_history длиной 1

Если одна валидная точка:

```text
partial = true
confidence = 0.3
```

`value` вычисляется по формуле window.

### score_history длиной 2

Если две валидные точки в одном window:

```text
partial = true
confidence = 0.6
```

### score_history длиной 3+

Если три и более валидных точки в одном window:

```text
partial = false для этого window
confidence = 0.9 для этого window
```

Но общий `partial` может остаться `true`, если отсутствуют другие масштабы.

### score_history содержит unknown window sizes

Точки с `window` не из `{"1h", "1d", "1w"}` пропускаются.

Добавить reason:

```text
"unknown_window_size"
```

Если после фильтрации не осталось валидных точек:

```text
return None
```

### threshold отсутствует

Использовать:

```text
threshold = 0.5
reason = "threshold_default_0_5"
```

### noise_baseline.percentile_75 присутствует

В M3.1 `noise_baseline` ещё не является частью dataclass, но интерфейс `resolve_threshold` проектируется под M3.4.

Правило:

```text
если threshold передан явно → использовать его
иначе если noise_baseline.percentile_75 есть → использовать его
иначе → 0.5
```

В M3.1 фактически используется threshold parameter или default 0.5.

## 3.3 Новый модуль app/objective/temporal_persistence.py

```python
"""
Temporal persistence component for Entropy-RG Objective Layer.

This component answers the question:
"Did the risk signal persist over time?"

It is the first Objective Layer component implemented in M3.1.
It reads only ObjectiveLayerContext.score_history and context.timestamp.
It does not activate Objective Layer, does not change final_score,
does not do I/O, and does not import app.scoring.

Formula summary:
- fixed windows: 1h, 1d, 1w
- exponential decay by window-specific half-life
- value_per_window = weighted signal above threshold / weighted max possible signal
- final value = mean over available windows
- confidence depends on history length per window
"""

from __future__ import annotations

from collections import defaultdict
from datetime import datetime, timezone
from typing import Iterable

from app.objective.types import (
    ObjectiveComponentResult,
    ObjectiveLayerContext,
    ScoreHistoryPoint,
)


WINDOW_SIZES = {"1h", "1d", "1w"}

HALF_LIVES_SECONDS = {
    "1h": 24 * 60 * 60,
    "1d": 7 * 24 * 60 * 60,
    "1w": 30 * 24 * 60 * 60,
}

DEFAULT_THRESHOLD = 0.5

CONFIDENCE_BY_LENGTH = {
    0: 0.0,
    1: 0.3,
    2: 0.6,
}

FULL_CONFIDENCE = 0.9


def clip_01(value: float) -> float:
    return max(0.0, min(1.0, float(value)))


def parse_timestamp(value: str) -> datetime | None:
    """
    Parse ISO-like timestamp as timezone-aware UTC datetime.

    Returns None if timestamp cannot be parsed.
    """
    if not value:
        return None

    try:
        normalized = value.replace("Z", "+00:00")
        parsed = datetime.fromisoformat(normalized)
    except ValueError:
        return None

    if parsed.tzinfo is None:
        parsed = parsed.replace(tzinfo=timezone.utc)

    return parsed.astimezone(timezone.utc)


def compute_decay_weight(age_seconds: float, half_life_seconds: float) -> float:
    if half_life_seconds <= 0:
        return 1.0
    age_seconds = max(0.0, float(age_seconds))
    return 0.5 ** (age_seconds / half_life_seconds)


def resolve_threshold(
    context_threshold: float | None,
    noise_baseline: object | None = None,
) -> tuple[float, list[str]]:
    """
    Returns (threshold, reasons).

    M3.1:
    - uses explicit threshold if provided;
    - otherwise attempts future-compatible noise_baseline.percentile_75;
    - otherwise uses DEFAULT_THRESHOLD = 0.5.
    """
    if context_threshold is not None:
        return clip_01(context_threshold), ["threshold_from_param"]

    if noise_baseline is not None:
        p75 = getattr(noise_baseline, "percentile_75", None)
        if p75 is not None:
            return clip_01(float(p75)), ["threshold_from_noise_baseline_p75"]

    return DEFAULT_THRESHOLD, ["threshold_default_0_5"]


def confidence_for_length(length: int) -> tuple[float, bool]:
    """
    Returns (confidence, partial_for_window).
    """
    if length <= 0:
        return 0.0, True
    if length in CONFIDENCE_BY_LENGTH:
        return CONFIDENCE_BY_LENGTH[length], True
    return FULL_CONFIDENCE, False


def compute_value_per_window(
    points: list[ScoreHistoryPoint],
    current_timestamp: datetime,
    threshold: float,
    window: str,
) -> tuple[float, float, bool, list[str]]:
    """
    Compute temporal persistence value for one window size.

    Returns:
        (value_per_window, confidence_per_window, partial_per_window, reasons)
    """
    reasons: list[str] = []
    half_life_seconds = HALF_LIVES_SECONDS[window]

    weighted_sum_above = 0.0
    weighted_sum_total = 0.0
    valid_points = 0

    for point in points:
        point_timestamp = parse_timestamp(point.timestamp)
        if point_timestamp is None:
            reasons.append("invalid_timestamp_in_history")
            continue

        age_seconds = (current_timestamp - point_timestamp).total_seconds()
        if age_seconds < 0:
            reasons.append("future_timestamp_clipped_to_zero_age")
            age_seconds = 0.0

        decay_weight = compute_decay_weight(age_seconds, half_life_seconds)
        score = clip_01(point.universal_risk)

        weighted_sum_above += decay_weight * max(0.0, score - threshold)
        weighted_sum_total += decay_weight * max(0.0, 1.0 - threshold)
        valid_points += 1

    if valid_points == 0:
        return 0.0, 0.0, True, reasons + ["no_valid_points_for_window"]

    if weighted_sum_total <= 0.0:
        return 0.0, 0.0, True, reasons + ["weighted_sum_total_zero"]

    value = clip_01(weighted_sum_above / weighted_sum_total)
    confidence, partial = confidence_for_length(valid_points)

    reasons.append(f"window_{window}_points_{valid_points}")

    if partial:
        reasons.append(f"window_{window}_partial_short_history")
    else:
        reasons.append(f"window_{window}_full_history")

    return value, confidence, partial, reasons


def group_history_by_window(
    score_history: Iterable[ScoreHistoryPoint],
) -> tuple[dict[str, list[ScoreHistoryPoint]], list[str]]:
    grouped: dict[str, list[ScoreHistoryPoint]] = defaultdict(list)
    reasons: list[str] = []

    for point in score_history:
        if point.window not in WINDOW_SIZES:
            reasons.append("unknown_window_size")
            continue
        grouped[point.window].append(point)

    return dict(grouped), reasons


def compute_temporal_persistence(
    context: ObjectiveLayerContext,
    threshold: float | None = None,
) -> ObjectiveComponentResult | None:
    """
    Compute temporal persistence of universal risk signal.

    Returns ObjectiveComponentResult if at least one valid history point
    in known windows exists. Returns None if score_history is empty or
    all points are invalid / unknown-window.

    This function is stateless and side-effect free.
    """
    if not context.score_history:
        return None

    current_timestamp = parse_timestamp(context.timestamp)
    if current_timestamp is None:
        return ObjectiveComponentResult(
            value=0.0,
            confidence=0.0,
            missing_inputs=["timestamp"],
            reasons=["invalid_context_timestamp"],
            partial=True,
        )

    # Future-compatible: M3.4 may add context.noise_baseline.
    noise_baseline = getattr(context, "noise_baseline", None)
    resolved_threshold, threshold_reasons = resolve_threshold(
        context_threshold=threshold,
        noise_baseline=noise_baseline,
    )

    grouped, grouping_reasons = group_history_by_window(context.score_history)

    if not grouped:
        return None

    value_by_window: dict[str, float] = {}
    confidence_by_window: dict[str, float] = {}
    point_count_by_window: dict[str, int] = {}
    reasons: list[str] = []
    partial = False

    reasons.extend(threshold_reasons)
    reasons.extend(grouping_reasons)

    missing_inputs: list[str] = []

    for window in ("1h", "1d", "1w"):
        points = grouped.get(window, [])
        if not points:
            missing_inputs.append(f"score_history.window.{window}")
            partial = True
            continue

        value, confidence, window_partial, window_reasons = compute_value_per_window(
            points=points,
            current_timestamp=current_timestamp,
            threshold=resolved_threshold,
            window=window,
        )

        value_by_window[window] = value
        confidence_by_window[window] = confidence
        point_count_by_window[window] = len(points)
        reasons.extend(window_reasons)

        if window_partial:
            partial = True

    if not value_by_window:
        return None

    value = clip_01(sum(value_by_window.values()) / len(value_by_window))

    confidence_denominator = sum(point_count_by_window.values())
    if confidence_denominator <= 0:
        confidence = 0.0
    else:
        confidence = clip_01(
            sum(
                confidence_by_window[window] * point_count_by_window[window]
                for window in confidence_by_window
            )
            / confidence_denominator
        )

    if grouping_reasons:
        partial = True

    if len(value_by_window) < len(WINDOW_SIZES):
        partial = True
        reasons.append("temporal_persistence_missing_window_scales")

    reasons.append(
        f"temporal_persistence_present_in_{len(value_by_window)}_of_3_window_scales"
    )

    return ObjectiveComponentResult(
        value=value,
        confidence=confidence,
        missing_inputs=missing_inputs,
        reasons=reasons,
        partial=partial,
    )
```

### Примечания к реализации

- `app/objective/temporal_persistence.py` не импортирует `app.scoring`.
- Функция stateless.
- Нет I/O.
- Threshold clipped в `[0, 1]`.
- Future timestamps не ломают расчёт.
- Unknown windows пропускаются.
- Пустая история возвращает `None`.

Status: implemented in M3.1, informational only.

temporal_persistence measures whether universal risk persisted across time

- future M3.4 `noise_baseline.percentile_75` when available;

## 6. Риски

## Risk 1: integration с integrate_scores меняет final_score

### Что может пойти не так

Temporal persistence случайно попадёт в weighted_base или final formula.

### Detection

- `test_final_score_unchanged_after_m3_1`;
- сравнение с `tests/fixtures/m1_4_baseline_scores.jsonl`.

### Mitigation

- Передавать temporal persistence только в `objective_component_scores`.
- Не менять `universal_risk`.
- Не менять `final_score`.

## Risk 2: timezone parsing несовпадение

### Что может пойти не так

`score_history.timestamp` и `context.timestamp` в разных timezone или без timezone. Возраст может быть посчитан неверно.

### Detection

- `test_decay_with_invalid_timestamps_handles_gracefully`;
- добавить tests на `Z`, `+00:00`, naive timestamp.

### Mitigation

- Всегда нормализовать timestamp в UTC.
- Naive timestamp трактовать как UTC.
- Невалидные timestamps пропускать с reason `invalid_timestamp_in_history`.

## Risk 3: разные window_size в одном score_history

### Что может пойти не так

ENRA присылает unknown windows: `15m`, `3d`, `monthly`. Компонента может упасть или исказить результат.

### Detection

- `test_unknown_window_skipped_with_reason`.

### Mitigation

- Фильтровать по `WINDOW_SIZES`.
- Unknown windows пропускать.
- Добавлять reason `unknown_window_size`.

## Risk 4: confidence одной партии перекрывает другую

### Что может пойти не так

Например, `1h` имеет 100 точек, `1d` имеет 2 точки. Взвешенная confidence будет доминироваться `1h` и скрывать слабость `1d`.

### Detection

- test с разной длиной по масштабам;
- проверка reasons с `window_<window>_points_<n>`.

### Mitigation

- В reasons включать длину истории по каждому масштабу.
- В future M3.6 можно добавить `confidence_by_window` в debug output. [OPEN_QUESTION]

## Risk 5: будущая интеграция M3.4 не сломает M3.1

### Что может пойти не так

Когда появится `noise_baseline.percentile_75`, threshold станет динамическим, и temporal value изменится.

### Detection

- integration test с фиктивным `noise_baseline.percentile_75`.

### Mitigation

- `resolve_threshold` уже в M3.1 принимает noise_baseline.
- reasons показывают источник threshold:
  - `threshold_from_param`;
  - `threshold_from_noise_baseline_p75`;
  - `threshold_default_0_5`.

## Risk 6: производительность на длинной истории

### Что может пойти не так

ENRA может прислать десятки тысяч points, что замедлит scoring.

### Detection

- performance smoke test на 10k points.

### Mitigation

- M3.1 не делает I/O, но может ограничивать обработку разумным max length. [OPEN_QUESTION]
- Рекомендуется ENRA передавать already-windowed history, а не raw event stream.

## Risk 7: future timestamps и отрицательный age

### Что может пойти не так

Точки из будущего дадут decay weight > 1, если age отрицательный.

### Detection

- test with future timestamp.

### Mitigation

- `age_seconds = max(0, age_seconds)`.
- Добавить reason `future_timestamp_clipped_to_zero_age`.

## Risk 8: disagreement между заданием и partial semantics для single-scale stable trend

### Что может пойти не так

Synthetic test может ожидать `partial=False` для 6 точек в одном `1d` window, но M3.1 решение говорит: missing scales → aggregated partial=True.

### Detection

- scenario test review.

### Mitigation

- Зафиксировать правило: если доступны не все 3 масштаба, aggregated partial=True.
- Если автор хочет иначе, изменить решение M3.1 до реализации. [OPEN_QUESTION]
