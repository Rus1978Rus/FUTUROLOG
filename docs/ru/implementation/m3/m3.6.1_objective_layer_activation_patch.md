## 1. Сводка

M3.6.1 активирует Objective Layer на запросах, где ENRA передаёт достаточно objective context. Вводится `universal_raw`, сохраняется `universal_risk` для backward compatibility, добавляется агрегатор `compute_objective_risk`, включается activation rule (`>= 3 active components` и обязательное наличие `scale_stability`), вводятся поля `objective_confidence`, `objective_layer_partial`, `active_components`, `missing_components`, `activation_blocked_reason`, а `final_score` начинает вычисляться по формуле `universal_raw × (alpha + (1 − alpha) × objective_risk_or_1) − gamma × trust_adjustment`. Главный критерий безопасности: `trust_adjustment` вычитается ровно один раз.

## 2. Изменения формулы

### 2.1 До M3.6.1: M1.4–M3.5

Текущая формула до активации Objective Layer:

```text
weighted_base = sum(weights × component_scores) − gamma × trust_adjustment
universal_risk = weighted_base + confluence_bonus
final_score = universal_risk
```

Эквивалентно:

```text
final_score =
    sum(weights × component_scores)
    + confluence_bonus
    − gamma × trust_adjustment
```

До M3.6.1 Objective Layer вычислял отдельные component scores, но не влиял на `final_score`.

### 2.2 После M3.6.1

Целевая формула:

```text
weighted_base_without_trust =
    sum(weights × component_scores)

universal_raw =
    weighted_base_without_trust + confluence_bonus

universal_risk =
    universal_raw − gamma × trust_adjustment

final_score =
    universal_raw × (alpha + (1 − alpha) × objective_risk_or_1)
    − gamma × trust_adjustment
```

Где:

```text
objective_risk_or_1 =
    objective_risk, если objective_layer_active = true
    1.0, если objective_layer_active = false
```

В M3.6.1:

```text
alpha = 0.5
gamma = 0.07
weights_version = "preprint-v1-uncalibrated/objective-mvp-v1"
model_version = "entropy-rg-v3.6.1-objective-active"
```

### 2.3 Поведение при неактивном слое

Если Objective Layer не активен:

```text
objective_layer_active = false
objective_risk_or_1 = 1.0
```

Тогда:

```text
final_score =
    universal_raw × (alpha + (1 − alpha) × 1.0)
    − gamma × trust_adjustment
```

Поскольку:

```text
alpha + (1 − alpha) × 1.0 = 1.0
```

получаем:

```text
final_score =
    universal_raw − gamma × trust_adjustment
    = universal_risk
```

Это означает, что на request без достаточного objective context M3.6.1 вырождается в поведение M1.4–M3.5. Поэтому старый baseline без objective context должен остаться численно идентичным.

### 2.4 Trust adjustment вычитается ровно один раз

Критическое правило M3.6.1:

```text
trust_adjustment НЕ входит в universal_raw.
trust_adjustment НЕ входит в multiplier.
trust_adjustment НЕ должен вычитаться из universal_risk перед умножением.
trust_adjustment применяется только в финальной формуле.
```

Правильная формула:

```text
final_score =
    universal_raw × (alpha + (1 − alpha) × objective_risk_or_1)
    − gamma × trust_adjustment
```

Неправильная формула:

```text
final_score =
    universal_risk × (alpha + (1 − alpha) × objective_risk_or_1)
    − gamma × trust_adjustment
```

Почему неправильно: `universal_risk` уже содержит `− gamma × trust_adjustment`. Если потом вычесть `trust_adjustment` ещё раз, получится двойное наказание.

Контрольный пример:

```text
universal_raw = 0.8
trust_adjustment = 0.1
gamma = 0.07
alpha = 0.5
objective_risk = 1.0
```

Правильно:

```text
final_score = 0.8 × (0.5 + 0.5 × 1.0) − 0.07 × 0.1
            = 0.8 × 1.0 − 0.007
            = 0.793
```

Если получилось `0.786`, значит `trust_adjustment` был вычтен дважды.

## 3. Activation rule

### 3.1 Active компонент

Objective-компонента считается active, если:

```text
result is not None
AND result.confidence >= 0.3
```

Компонента считается missing, если:

```text
result is None
OR result.confidence < 0.3
OR component was not invoked because its context field is missing
```

Для low-confidence exclusion в reasons добавляется:

```text
low_confidence_<component_name>
```

### 3.2 Активация слоя

Objective Layer активируется на уровне конкретного request:

```text
objective_layer_active = true
если:
    len(active_components) >= 3
    AND "scale_stability" in active_components
```

`alpha_active` должен строго совпадать с `objective_layer_active`:

```text
alpha_active = objective_layer_active
```

### 3.3 Граничные случаи активации

| Ситуация | layer_active | objective_risk | activation_blocked_reason |
|---|---:|---:|---|
| Все 5 компонент missing | false | null | `all_components_missing` |
| 2 active, scale_stability среди них | false | null | `fewer_than_3_active_components` |
| 3 active, scale_stability missing | false | null | `scale_stability_missing` |
| 3 active, scale_stability есть | true | число | null |
| 5 active, scale_stability есть | true | число | null |
| 4 active, одна confidence=0.29 исключена, остаётся 3 + scale | true | число | null |
| 4 active, после low confidence остаётся 2 + scale | false | null | `fewer_than_3_active_components` |

Если слой не активен:

```text
objective_risk = null
objective_confidence = null
objective_layer_partial = false
objective_layer_active = false
alpha_active = false
final_score = universal_risk
```

Если слой активен:

```text
objective_risk ∈ [0, 1]
objective_confidence ∈ [0, 1]
objective_layer_partial = any(active_component.partial)
objective_layer_active = true
alpha_active = true
```

## 4. Patch для кода

### 4.1 Новый модуль app/objective/aggregator.py

Создать новый файл `app/objective/aggregator.py`.

```python
"""
Objective Layer aggregator for Entropy-RG v3.6.1.

This module aggregates already-computed Objective Layer component results.

It does not:
- compute individual objective components;
- call app.scoring;
- do I/O;
- mutate state;
- activate global system flags.

Activation is request-local and depends only on supplied component results.

Activation rule:
    layer_active = len(active_components) >= 3
                   and "scale_stability" in active_components
"""

from __future__ import annotations

from dataclasses import dataclass, field
from typing import Dict, Optional

from app.objective.types import ObjectiveComponentResult


OBJECTIVE_WEIGHTS: dict[str, float] = {
    "scale_stability": 0.25,
    "temporal_persistence": 0.20,
    "source_redundancy": 0.20,
    "observer_agreement": 0.20,
    "noise_separation": 0.15,
}

MIN_COMPONENT_CONFIDENCE = 0.3
MIN_ACTIVE_COMPONENTS = 3
REQUIRED_COMPONENT_FOR_ACTIVATION = "scale_stability"


@dataclass
class ObjectiveRiskResult:
    value: Optional[float]
    confidence: Optional[float]
    partial: bool
    active_components: list[str] = field(default_factory=list)
    missing_components: list[str] = field(default_factory=list)
    reasons: list[str] = field(default_factory=list)
    layer_active: bool = False
    activation_blocked_reason: Optional[str] = None


def clip_01(value: float) -> float:
    return max(0.0, min(1.0, float(value)))


def _component_is_active(result: ObjectiveComponentResult | None) -> bool:
    if result is None:
        return False
    return float(result.confidence) >= MIN_COMPONENT_CONFIDENCE


def _activation_blocked_reason(active_components: list[str]) -> str | None:
    if not active_components:
        return "all_components_missing"

    if len(active_components) < MIN_ACTIVE_COMPONENTS:
        return "fewer_than_3_active_components"

    if REQUIRED_COMPONENT_FOR_ACTIVATION not in active_components:
        return "scale_stability_missing"

    return None


def compute_objective_risk(
    objective_component_results: Dict[str, ObjectiveComponentResult | None],
) -> ObjectiveRiskResult:
    """
    Aggregate Objective Layer component results into objective_risk.

    Missing behavior:
    - result is None → missing;
    - result.confidence < 0.3 → missing;
    - missing component weights are redistributed proportionally
      over active components.

    Returns ObjectiveRiskResult with layer activation metadata.
    """
    active_components: list[str] = []
    missing_components: list[str] = []
    reasons: list[str] = []

    for component_name in OBJECTIVE_WEIGHTS:
        result = objective_component_results.get(component_name)

        if result is None:
            missing_components.append(component_name)
            reasons.append(f"missing_{component_name}")
            continue

        if float(result.confidence) < MIN_COMPONENT_CONFIDENCE:
            missing_components.append(component_name)
            reasons.append(f"low_confidence_{component_name}")
            continue

        active_components.append(component_name)

    blocked_reason = _activation_blocked_reason(active_components)

    if blocked_reason is not None:
        return ObjectiveRiskResult(
            value=None,
            confidence=None,
            partial=False,
            active_components=active_components,
            missing_components=missing_components,
            reasons=reasons + [blocked_reason],
            layer_active=False,
            activation_blocked_reason=blocked_reason,
        )

    active_weight_sum = sum(OBJECTIVE_WEIGHTS[name] for name in active_components)

    if active_weight_sum <= 0.0:
        return ObjectiveRiskResult(
            value=None,
            confidence=None,
            partial=False,
            active_components=active_components,
            missing_components=missing_components,
            reasons=reasons + ["active_weight_sum_zero"],
            layer_active=False,
            activation_blocked_reason="active_weight_sum_zero",
        )

    objective_value = 0.0
    objective_confidence = 0.0
    partial = False

    for component_name in active_components:
        result = objective_component_results[component_name]
        assert result is not None

        normalized_weight = OBJECTIVE_WEIGHTS[component_name] / active_weight_sum
        objective_value += normalized_weight * clip_01(result.value)
        objective_confidence += normalized_weight * clip_01(result.confidence)

        if bool(result.partial):
            partial = True

    objective_value = clip_01(objective_value)
    objective_confidence = clip_01(objective_confidence)

    reasons.append("objective_layer_active")
    reasons.append(f"active_component_count_{len(active_components)}")

    return ObjectiveRiskResult(
        value=objective_value,
        confidence=objective_confidence,
        partial=partial,
        active_components=active_components,
        missing_components=missing_components,
        reasons=reasons,
        layer_active=True,
        activation_blocked_reason=None,
    )
```

#### 4.2.3 Новая final_score формула

```python
DEFAULT_ALPHA = 0.5  # changed from metadata 0.3 in M1; schedule is M3.6.2
DEFAULT_GAMMA = 0.07  # unchanged

if objective_risk_result.layer_active:
    objective_risk_or_1 = objective_risk_result.value
    alpha_active = True
else:
    objective_risk_or_1 = 1.0
    alpha_active = False

final_score = (
    universal_raw * (DEFAULT_ALPHA + (1.0 - DEFAULT_ALPHA) * objective_risk_or_1)
    - DEFAULT_GAMMA * trust_adjustment
)
```

Safety assertion:

```python
if not objective_risk_result.layer_active:
    assert abs(final_score - universal_risk) < 1e-12
```

Optional helper for testing:

```python
def compute_final_score(
    universal_raw: float,
    trust_adjustment: float,
    objective_risk_or_1: float,
    alpha: float = DEFAULT_ALPHA,
    gamma: float = DEFAULT_GAMMA,
) -> float:
    return (
        universal_raw * (alpha + (1.0 - alpha) * objective_risk_or_1)
        - gamma * trust_adjustment
    )
```

This helper is recommended because it makes `test_trust_adjustment_subtracted_exactly_once` direct and isolated.

def test_trust_adjustment_subtracted_exactly_once():
    """

    universal_raw = 0.8

## Objective Layer Activation

Status: activated in M3.6.1.

### Formula

M3.6.1 introduces universal_raw:

weighted_base_without_trust = sum(weights × component_scores)
universal_raw = weighted_base_without_trust + confluence_bonus
universal_risk = universal_raw − gamma × trust_adjustment

final_score =
    universal_raw × (alpha + (1 − alpha) × objective_risk_or_1)
    − gamma × trust_adjustment

objective_risk_or_1 = objective_risk when Objective Layer is active,

### Backward compatibility

If Objective Layer is not active for a request, final_score equals

Objective Layer is active when:
- at least 3 Objective components are active;

M3.6.1 uses alpha = 0.5.
Alpha schedule is deferred to M3.6.2.

### Trust adjustment

trust_adjustment is subtracted exactly once in the final formula.

- assert `final_score == universal_risk`.

Detection: aggregator activation scenario tests.

- centralize activation rule in `compute_objective_risk`;
