# M1.3 Scoring Rename Patch

# Canonical scoring rename + trust_adjustment + canonical_mapping.py

Статус: patch-документ для M1.3  
Проект: «Футуролог»  
Основание: `migration_plan_v3_0.md`, `m1_2_domain_rename_patch.md`  
Цель: canonical scoring rename без изменения математического смысла score

Важно: этот patch-документ подготовлен по согласованным решениям M1.1/M1.2 и заданию M1.3. Фактический архив `entropy_rg_anomaly_detector_EN_v2_2_FINAL.zip` в текущем контексте не открыт, поэтому места, где требуется сверка с реальным кодом, помечены `[REQUIRES_VERIFICATION]`.

## Сводка

M1.3 выполняет canonical scoring rename после доменного переименования M1.2: ключи `trust`, `residue`, `sequential`, `graph` переименовываются в `trust_penalty`, `rg_persistence_score`, `sequential_anomaly_score`, `graph_risk`; `robustness` удаляется из `DEFAULT_WEIGHTS` и выносится в отдельный `trust_adjustment`, применяемый со знаком минус. Создаётся новый файл `app/canonical_mapping.py` с константами и mapping-функциями. Формулы, пороги, смысл confluence-логики и числовые веса не меняются. Для доказательства числовой эквивалентности в M1.3 фиксируется `DEFAULT_GAMMA = 0.05`, равный старому весу `robustness`; переход к `gamma = 0.07` относится к M1.4. Dual output, API `canonical_component_scores`, `weights_version`, `calibration_status`, `alpha`, Objective Layer и обновление `SYSTEM_META` в M1.3 не добавляются.

### Обоснование

- `gibbs` остаётся legacy building block.
- `surprise` остаётся legacy building block.
- `residue` становится публичным canonical key `rg_persistence_score`.
- `sequential` становится `sequential_anomaly_score`.
- `graph` становится `graph_risk`.
- `trust` становится `trust_penalty`.
- `robustness` удаляется из `DEFAULT_WEIGHTS`, потому что это discount/modifier, а не risk component.
- `DEFAULT_GAMMA = 0.05` нужен только в M1.3 для числовой эквивалентности старой формуле.

### Что нельзя менять

- Значения весов 0.25, 0.22, 0.18, 0.18, 0.12, 0.10.
- Порядок применения весов в итоговой формуле, кроме замены старых имён на новые.
- Любые threshold values.

## app/canonical_mapping.py

Это новый файл. Он не импортирует scoring, не содержит формул, не делает I/O и не реализует новые компоненты.

```python
"""
Canonical mapping module for Entropy-RG v3.0-domain-neutral.

Translates legacy scoring keys to canonical names per ERG-CAD
preprint and architecture v1.1.

This module does NOT contain scoring formulas, NOT compute new
components, NOT do file/network I/O.
"""

from __future__ import annotations

from typing import Dict


# Constants

LEGACY_TO_CANONICAL: Dict[str, str] = {
    "residue": "rg_persistence_score",
    "sequential": "sequential_anomaly_score",
    "graph": "graph_risk",
    "trust": "trust_penalty",
}

CANONICAL_TO_LEGACY: Dict[str, str] = {
    v: k for k, v in LEGACY_TO_CANONICAL.items()
}

# gibbs and surprise remain legacy building blocks
# robustness is excluded — it becomes trust_adjustment


def map_legacy_to_canonical(legacy_scores: dict) -> dict:
    """
    Translate legacy scoring keys to canonical names.

    - residue -> rg_persistence_score
    - sequential -> sequential_anomaly_score
    - graph -> graph_risk
    - trust -> trust_penalty
    - gibbs, surprise -> not in canonical output
    - robustness -> not in canonical output (handled separately)
    """
    canonical = {}
    for legacy_key, value in legacy_scores.items():
        if legacy_key in LEGACY_TO_CANONICAL:
            canonical[LEGACY_TO_CANONICAL[legacy_key]] = value
    return canonical


def map_canonical_to_legacy(canonical_scores: dict) -> dict:
    """
    Reverse mapping for backward compatibility.
    """
    legacy = {}
    for canonical_key, value in canonical_scores.items():
        if canonical_key in CANONICAL_TO_LEGACY:
            legacy[CANONICAL_TO_LEGACY[canonical_key]] = value
    return legacy


def extract_trust_adjustment(legacy_payload: dict) -> float:
    """
    Extract trust_adjustment from legacy robustness/discount.

    Sign convention: trust_adjustment is positive in storage,
    applied with minus in final formula.
    Does not change sign without explicit decision.
    """
    return float(legacy_payload.get("robustness_discount", 0.0))


def validate_dual_output_keys(output: dict) -> None:
    """
    Validate that the output dict contains expected canonical keys.
    Used by tests, not by scoring logic.
    """
    required = {
        "rg_persistence_score",
        "sequential_anomaly_score",
        "graph_risk",
        "trust_penalty",
    }
    missing = required - set(output.keys())
    if missing:
        raise ValueError(f"Missing canonical keys: {missing}")
```

```python
import json
from pathlib import Path


def load_jsonl(path: str):
    rows = []
    for line in Path(path).read_text().splitlines():
        line = line.strip()
        if line:
            rows.append(json.loads(line))
    return rows


def test_score_v3_0_equals_v2_2_baseline():
    """
    M1.3 must be numerically equivalent to M1.2/v2.2 baseline.

    Required precondition:
    - /tmp/v3_0_m1_2_scores.jsonl exists
    - /tmp/v3_0_m1_3_scores.jsonl exists

    These files are produced by the bash checklist.
    """
    old = load_jsonl("/tmp/v3_0_m1_2_scores.jsonl")
    new = load_jsonl("/tmp/v3_0_m1_3_scores.jsonl")

    assert len(old) == len(new)

    for index, (old_row, new_row) in enumerate(zip(old, new)):
        assert abs(old_row["final_score"] - new_row["final_score"]) < 1e-9, (
            index,
            old_row["final_score"],
            new_row["final_score"],
        )
```

- Добавить test на non-zero bonus with canonical keys.
- Не удалять old confluence tests до прохождения новых.

## Risk 2: weighted_base считается на старых ключах

## Risk 3: trust_adjustment знак

### Что может пойти не так

`trust_adjustment` должен храниться как positive value и применяться со знаком минус. Если инвертировать значение или поменять знак, high adjustment увеличит score вместо снижения.

### Где

- `compute_trust_adjustment`;
- `integrate_scores`;
- tests.

### Detection

Synthetic test:

```python
def test_high_trust_adjustment_reduces_score():
    low = integrate_scores(..., trust_adjustment=0.0, gamma=0.05)["final_score"]
    high = integrate_scores(..., trust_adjustment=1.0, gamma=0.05)["final_score"]
    assert high < low
```

### Mitigation

- Не менять sign convention.
- В комментарии функции указать: positive in storage, minus in formula.
- `DEFAULT_GAMMA = 0.05` в M1.3.
