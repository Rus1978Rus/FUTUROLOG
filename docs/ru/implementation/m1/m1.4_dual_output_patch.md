# M1.4 Dual Output Patch

# Dual output API + metadata fields + переход gamma 0.05 → 0.07

Статус: patch-документ для M1.4  
Проект: «Футуролог»  
Основание: `migration_plan_v3_0.md`, `m1_2_domain_rename_patch.md`, `m1_3_scoring_rename_patch.md`  
Цель: завершить API-слой v3.0-domain-neutral через dual output, metadata и новый baseline

Важно: этот patch-документ подготовлен по согласованным решениям M1.1–M1.3. Фактический архив `entropy_rg_anomaly_detector_EN_v2_2_FINAL.zip` в текущем контексте не открыт, поэтому места, где требуется сверка с реальным кодом, помечены `[REQUIRES_VERIFICATION]`.

## Сводка

M1.4 завершает публичный API-слой Entropy-RG v3.0-domain-neutral: добавляет dual output (`legacy_component_scores` и `canonical_component_scores`), metadata-поля (`model_version`, `weights_version`, `calibration_status`, `alpha`, `gamma`, `alpha_active`, `objective_layer_active`), обновляет `SYSTEM_META`, расширяет healthcheck, сохраняет backward compatibility через deprecated alias `component_scores = legacy_component_scores`, и переводит `DEFAULT_GAMMA` с 0.05 на 0.07. Это намеренно меняет численный baseline относительно M1.3, поэтому создаётся новый M1.4 baseline JSONL. Objective Layer в M1.4 не реализуется: `objective_risk = None`, `objective_component_scores = {}`, `objective_layer_active = False`; alpha-формула не применяется, `final_score = universal_risk`.

### build_dual_output

```python
# СТАЛО
def build_dual_output(
    legacy_scores: dict,
    trust_adjustment: float,
    universal_risk: float,
    confluence_bonus: float,
    reasons: list,
    gamma: float = DEFAULT_GAMMA,
    alpha: float = DEFAULT_ALPHA,
) -> dict:
    """
    Собирает полный dual output v3.0.

    - legacy_component_scores: все 7 старых ключей, включая
      robustness как mapped from trust_adjustment.
    - canonical_component_scores: canonical names plus identity
      building blocks gibbs and surprise.
    - objective_component_scores: empty dict.
    - objective_risk: None.
    - alpha_active: False.
    - objective_layer_active: False.
    - final_score = universal_risk.
    """
    legacy_component_scores = {
        "gibbs": legacy_scores.get("gibbs"),
        "residue": legacy_scores.get("residue"),
        "sequential": legacy_scores.get("sequential"),
        "surprise": legacy_scores.get("surprise"),
        "graph": legacy_scores.get("graph"),
        "trust": legacy_scores.get("trust"),
        "robustness": trust_adjustment,
    }

    canonical_component_scores = {
        "gibbs": legacy_scores.get("gibbs"),
        "rg_persistence_score": legacy_scores.get("residue"),
        "sequential_anomaly_score": legacy_scores.get("sequential"),
        "surprise": legacy_scores.get("surprise"),
        "graph_risk": legacy_scores.get("graph"),
        "trust_penalty": legacy_scores.get("trust"),
    }

    meta = get_system_meta()

    output = {
        "legacy_component_scores": legacy_component_scores,
        "canonical_component_scores": canonical_component_scores,
        "trust_adjustment": trust_adjustment,
        "objective_component_scores": {},
        "universal_risk": universal_risk,
        "objective_risk": None,
        "final_score": universal_risk,
        "confluence_bonus": confluence_bonus,
        "reasons": reasons,
        "model_version": meta["model_version"],
        "weights_version": meta["weights_version"],
        "calibration_status": meta["calibration_status"],
        "alpha": alpha,
        "gamma": gamma,
        "alpha_active": False,
        "objective_layer_active": False,
        "component_scores": legacy_component_scores,  # DEPRECATED alias
    }
    return output
```

### Важные правила для build_dual_output

- `final_score = universal_risk`.
- `objective_risk = None`, не 0.0 и не 1.0.
- `objective_component_scores = {}`.
- `alpha_active = False`.
- `objective_layer_active = False`.
- `component_scores` должен быть identity-копией `legacy_component_scores`.
- `legacy_component_scores["robustness"] = trust_adjustment`.
- Нельзя делать `legacy_component_scores["robustness"] = -trust_adjustment`.
- Нельзя умножать `robustness` на `gamma` в legacy block.
- `gamma` применяется только при расчёте score в `app/scoring.py`.

```python
def load_jsonl(path: str):
    rows = []

        line = line.strip()
        if line:

        assert abs(a["final_score"] - b["final_score"]) < 1e-9, (

    old = load_jsonl("/tmp/v3_0_m1_3_scores.jsonl")
    new = load_jsonl("/tmp/v3_0_m1_4_scores.jsonl")

    assert len(old) == len(new)

    differences = [
        abs(a["final_score"] - b["final_score"])
        for a, b in zip(old, new)
    ]

    assert any(delta > 1e-12 for delta in differences)
```

[REQUIRES_VERIFICATION] If some fixtures have `trust_adjustment = 0`, scores may not differ. In that case add at least one fixture with non-zero trust_adjustment.

## Critical risks M1.4

## Risk 1: gamma transition не зафиксирован baseline

### Что может пойти не так

M1.4 меняет `gamma` с 0.05 на 0.07. Если новый baseline не зафиксировать, будущие изменения нельзя будет отличить от M1.4 planned shift.

### Detection

- Проверить наличие `tests/fixtures/m1_4_baseline_scores.jsonl`.
- Запустить `pytest tests/test_scoring_baseline_m1_4.py -v`.

### Mitigation

- После первого зелёного запуска создать baseline:
  `python app/main.py --actors data/actors.csv --events data/events.csv > tests/fixtures/m1_4_baseline_scores.jsonl`.
- Закоммитить baseline вместе с M1.4.

## Risk 2: dual output ломает API клиентов

### Что может пойти не так

Клиенты могут ожидать `component_scores` и не знать о новых блоках.

### Detection

- API snapshot tests.
- Проверка `component_scores in response`.

### Mitigation

- Сохранить `component_scores` как deprecated alias на `legacy_component_scores`.
- Deprecated endpoint `/score-seller` возвращает legacy-only response.

## Risk 3: alpha и objective_risk воспринимаются как уже работающие

### Что может пойти не так

Клиенты увидят `alpha = 0.3` и могут считать, что alpha-формула уже применяется.

### Detection

- Проверить response:
  - `alpha_active is False`;
  - `objective_layer_active is False`;
  - `objective_risk is None`.

### Mitigation

- В каждом response возвращать `alpha_active = False`.
- В README/dashboard писать `Objective Layer is not implemented in M1.4`.

## Risk 4: SYSTEM_META рассинхронизирован между modules

### Что может пойти не так

`security.py`, `scoring.py` и `healthcheck.py` возвращают разные версии metadata.

### Detection

- `tests/test_metadata_consistency.py`.
- grep hardcoded version strings.

### Mitigation

- Единый источник истины — `get_system_meta()` в `app/canonical_mapping.py`.
- Остальные модули импортируют metadata.

## Risk 5: HMAC snapshots ломаются от добавления metadata

### Что может пойти не так

Payload для подписи изменится, и старые HMAC fixtures больше не совпадут.

### Detection

- Security/HMAC tests fail.
- Snapshot diff shows metadata fields.

### Mitigation

- Обновить HMAC fixtures как часть M1.4.
- Документировать, что hash change ожидаем из-за payload schema change.
- Не менять сам HMAC algorithm.

## Risk 6: legacy robustness semantics искажена

### Что может пойти не так

Старые клиенты читали `robustness` как positive discount value. Если в legacy block положить отрицательное значение или scaled value, compatibility сломается.

### Detection

- `test_dual_output_legacy_robustness_equals_trust_adjustment`.

### Mitigation

- В `legacy_component_scores` писать:
  `robustness = trust_adjustment`.
- Не применять sign или gamma внутри legacy block.

## Risk 7: dashboard отображает objective layer как 0 вместо null

### Что может пойти не так

Пользователь подумает, что objective score рассчитан и равен 0, хотя слой не реализован.

### Detection

- Dashboard smoke test.
- Проверка UI text.

### Mitigation

- Показывать `not implemented`, а не число.
- В JSON: `objective_risk = None`.

## Risk 8: Deprecated endpoint возвращает новый dual output вместо legacy

### Что может пойти не так

Старый клиент, который вызывает `/score-seller`, получит новый response и сломается.

### Detection

- API test for deprecated endpoint response shape.
- Проверить отсутствие `canonical_component_scores` в deprecated response.

### Mitigation

- `convert_to_legacy_response(result)`.
- Отдельная `DeprecatedScoreResponse`.

## Risk 9: `component_scores` alias не identity-copy

### Что может пойти не так

`component_scores` может случайно указывать на canonical block, а не legacy block.

### Detection

- `test_dual_output_component_scores_equals_legacy_for_back_compat`.

### Mitigation

- В `build_dual_output` явно:
  `"component_scores": legacy_component_scores`.
