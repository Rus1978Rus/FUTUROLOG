# Документация FUTUROLOG — RU

Детальный рабочий слой, перенесённый из исходного handoff-пакета и систематизированный по назначению. См. корневой `PROVENANCE_MAP.md` для соответствия исходных и новых путей.

## Новые рабочие документы после миграции

- [Реестр межпроектных доноров v0.1](architecture/cross_project_donor_register_v0_1.md) — какие механизмы можно импортировать, адаптировать, оставить как reference (образец) или отклонить.
- [Objective / Coverage Design v0.1](architecture/objective_coverage_design_v0_1.md) — разделение measured score (измеренного результата), coverage (покрытия), независимости источников, свежести, полноты pipeline (маршрута), шума и effective confidence (эффективной уверенности).
- [Strategic Interaction Candidate v0.1](research/strategic_interaction_candidate_v0_1.md) — отложенный кандидатный слой памяти отношений, смены партнёров и сетевой избыточности; не часть текущего core (ядра).
- [Emerging Domain Assessment Candidate v0.1](research/emerging_domain_assessment_candidate_v0_1.md) — отложенная диагностика зрелости зарождающейся области по донору «Зерно и формула»; численные метрики донора не считаются откалиброванными.

Все документы имеют рабочие/кандидатные статусы и не являются заявлением о production-ready (готовности к промышленному использованию), validation (валидации) или завершённой интеграции.
