# M1.3 — Canonical Scoring Rename Patch

> English semantic mirror of the detailed Russian patch specification.

## Purpose

Introduce canonical scoring names, canonical mapping metadata, and explicit trust-adjustment terminology while preserving numeric behaviour.

## Preserved decisions

- Rename legacy scoring components through a versioned mapping layer.
- Preserve public compatibility with wrappers or aliases where required.
- Expose canonical reason codes and component keys.
- Apply trust adjustment as one bounded deduction only.
- Keep formula order explicit and covered by regression tests.
- Do not infer empirical equivalence or calibration from semantic renaming.

## Boundary

This milestone changes naming and representation. It must not silently change the actual scoring model.
