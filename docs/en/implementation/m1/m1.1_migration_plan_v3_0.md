# M1.1 — Migration Plan to Entropy-RG v3.0 Domain-Neutral

> English semantic mirror of the detailed Russian patch plan.

## Purpose

Inventory and sequence the migration from marketplace-specific `seller`/`listing` vocabulary to domain-neutral `actor`/`event` vocabulary.

## Preserved decisions

- Verify every affected runtime, test, data, storage, API, security, calibration, dashboard, and documentation file.
- Treat database and CSV migration as data work, not a search-and-replace operation.
- Preserve numeric scoring behaviour during domain renaming.
- Introduce compatibility aliases only where public interfaces require them, with an explicit removal version.
- Keep the M1 migration separate from Objective Layer activation.

## Completion criteria

The migration is complete only when code, schemas, datasets, tests, API responses, sealing payloads, documentation, and compatibility behaviour agree.

## Boundary

This document is an implementation proposal until reconciled with the actual source repository and verified by tests.
