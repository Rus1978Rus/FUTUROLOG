# M1.2 — Domain Rename Patch

> English semantic mirror of the detailed Russian patch specification.

## Purpose

Replace marketplace-specific `seller`/`listing` concepts with domain-neutral `actor`/`event` concepts without changing scoring semantics.

## Preserved decisions

- Rename public functions, helpers, feature extraction, aggregation, API fields, data models, and documentation consistently.
- Keep temporary deprecated aliases only when compatibility requires them.
- Mark every alias with an intended removal version.
- Do not modify formulas, weights, thresholds, or score ordering as part of this rename.
- Verify storage schemas and serialized payloads separately from Python identifiers.

## Boundary

A textual rename is insufficient if persisted data, tests, external clients, or sealing payloads still depend on legacy names.
