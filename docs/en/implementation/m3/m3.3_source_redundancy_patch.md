# M3.3 — Source Redundancy Patch

> English semantic mirror of the detailed Russian patch specification.

## Purpose

Estimate whether a signal is supported by multiple sufficiently independent sources.

## Preserved decisions

- Track source identity, provenance, dependence, and evidence contribution.
- Discount copied, syndicated, mirrored, or causally dependent reporting.
- Distinguish source count from independent source support.
- Return component value, confidence, reasons, missing inputs, and partial status.
- Keep source-independence logic explicit and auditable.

## Boundary

Many citations can originate from one underlying claim. Redundancy measures independent support, not link volume.
