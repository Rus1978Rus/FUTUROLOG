# M3.1 — Temporal Persistence Patch

> English semantic mirror of the detailed Russian patch specification.

## Purpose

Measure whether a signal persists across time instead of appearing as a one-off spike.

## Preserved decisions

- Use explicit `score_history`, declared windows, thresholds, and available noise-baseline information.
- Handle empty, one-point, two-point, and longer histories separately.
- Report `value`, `confidence`, `missing_inputs`, `reasons`, and `partial` status.
- Unknown windows or insufficient history must remain visible.
- Integrate the component without changing M1.4 behaviour when the Objective Layer is inactive.

## Boundary

Persistence does not prove causality or guarantee continuation. It only records that a structured signal survives across the observed history.
