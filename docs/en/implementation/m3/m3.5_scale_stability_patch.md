# M3.5 — Scale Stability Patch

> English semantic mirror of the detailed Russian patch specification.

## Purpose

Test whether a detected pattern remains coherent across analytical windows, aggregation levels, or graph scales.

## Preserved decisions

- Use explicit `scale_aggregates` and declared scale definitions.
- Penalize patterns that exist only at one arbitrary resolution.
- Report missing scales, incompatible aggregates, confidence, reasons, and partial coverage.
- Keep scale selection domain-aware and versioned.
- Preserve inactive-layer regression behaviour.

## Boundary

Cross-scale stability supports robustness, but it does not prove that the same causal process generated every scale-level pattern.
