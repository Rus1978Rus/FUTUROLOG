# M3.6.1 — Objective Layer Activation Patch

> English semantic mirror of the detailed Russian patch specification.

## Purpose

Activate the complete Objective Layer behind explicit validity checks and a protected compatibility fallback.

## Preserved decisions

- Activate only when at least one objective component is valid.
- Normalize weights over active components only.
- Return activation state, objective value, layer confidence, component detail, missing inputs, and partial status.
- Apply trust adjustment exactly once in the final integration path.
- Reproduce the M1.4 no-objective baseline exactly whenever the layer is inactive.
- Establish a separate full-objective regression baseline.

## Boundary

Activation means the software path is enabled. It does not mean the objective score has been calibrated or scientifically validated.
